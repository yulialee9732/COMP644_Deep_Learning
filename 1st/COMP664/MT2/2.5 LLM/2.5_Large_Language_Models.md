# 2.5 Large Language Models

### Autoregressive pretraining and generation

A decoder-only Transformer can learn from raw text by using each token as the prediction target for the prefix that precedes it. Training on many sequences builds a shared model of next-token probabilities. At inference time, an instruction, document, or conversation history can serve as the initial prefix. The resulting continuation can function as an answer, summary, or translation depending on the prompt.

The lecture distinguished a model's token-by-token generation from a system's use of several model calls. A system can first generate a plan, then draft, critique, or revise a response. Each generated intermediate result can become context for a later call.

### Empirical scaling laws and emergent abilities

The lecture discussed three factors that affect language-model test loss:

- **Model size**, measured in trainable parameters.
- **Training data**, often measured in tokens.
- **Training compute**, measured in operations such as FLOPs.

Scaling laws summarize empirical relationships between these factors and held-out loss. Over observed ranges, loss can follow approximate power-law trends as model size, training data, or compute grows. Measurements from smaller training runs can help estimate the loss of larger runs and guide compute allocation. The relationships are fitted over particular ranges, so extrapolation carries uncertainty.

Some benchmarks show a different pattern from aggregate loss. Performance on a task may stay near chance for smaller models and then improve sharply as scale increases. The lecture described this as an apparent *emergent ability* and raised the possibility that some tasks require several prerequisite abilities to work together. The observation depends on the task and how its performance is measured.

### Long-context attention

Full attention has a quadratic cost in sequence length because every query position is scored against every key position. For one head, \(L=1{,}000\) gives one million score entries and \(L=10{,}000\) gives one hundred million. A million-token sequence would give a trillion entries if the full dense matrix were formed. A causal mask removes future-token interactions but still permits a quadratic number of past-token pairs.

The lecture discussed sparse attention, which restricts the pairs that can interact, and approximate or linear attention, which changes the computation used to combine token information. Retrieval-augmented generation addresses a related context problem by retrieving relevant passages and putting them into the model's input, so the model can attend to those passages without processing the entire collection at once.

### Interpretability, ablation, and trust

Knowing the architecture and training objective leaves open the question of how a trained model produces a particular answer. Interpretability experiments can inspect internal activations and attention patterns or intervene in the computation. An **ablation** can remove an attention head and measure how predictions or task performance change. The effect is evidence about that component's role in the tested setting.

The classroom discussion connected interpretability to trust in public-facing or safety-relevant applications. It considered two kinds of evidence: an explanation of how a system reached a decision, and a record of how it behaves under testing and oversight. A system can perform well on familiar tasks while still failing under unfamiliar conditions. Repeated success can also lead users to rely on a system before they have evidence that it generalizes to the setting where they want to use it.
