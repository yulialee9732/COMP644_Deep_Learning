# 2.4 Transformer Architectures

### Transformer blocks

A Transformer stacks blocks that alternately mix information across tokens and transform each token's representation.

1. **Multi-head attention** mixes information across positions.
2. **Position-wise feed-forward network** applies the same learned nonlinear transformation independently to every position. A common design expands each vector from \(d_{\mathrm{model}}\) to \(4d_{\mathrm{model}}\), applies an activation, and projects it back to \(d_{\mathrm{model}}\). The expanded layer gives the network room to represent different features of each contextualized token.

Both sublayers use residual connections and normalization. With post-normalization, a sublayer takes the form \(\operatorname{LN}(x+F(x))\). With pre-normalization, it takes the form \(x+F(\operatorname{LN}(x))\). Layer normalization acts across the features of each token vector and can learn a scale and bias. Each block has its own projection and feed-forward weights, while the feed-forward weights within a block are shared across positions.

### Token embeddings, positions, and output logits

A token embedding table provides one vector per vocabulary item. Attention by itself is equivariant to a permutation of the input rows when it has no position information or position-dependent mask. To represent order, a model can add a learned position vector \(p_i\) to the token embedding \(e(w_i)\) at position \(i\). A token such as “Carolina” then has a different initial representation in position one than in position three.

To predict a token, the model uses an output projection, sometimes called **unembedding**, to map a final hidden vector to one logit per vocabulary item. Some models tie the output weights to the input embedding weights, using the embedding matrix transposed for the output projection. Embeddings can be updated through backpropagation.

Tokenization also affects how many positions an input occupies. With subword tokenization, a long word can occupy several positions, and comparable text in different languages can have different token counts. The lecture used morphologically rich languages such as Turkish and Icelandic to illustrate why token count and word count can behave differently.

### Where the parameters are

For a standard block with model width \(d\) and feed-forward width \(4d\), the attention projections contribute about \(4d^2\) weights, and the feed-forward projections contribute about \(8d^2\). With \(N\) blocks and one tied token embedding and output matrix for a vocabulary of size \(V\), an approximate count is \(12Nd^2+Vd\), before adding position embeddings, normalization parameters, and biases. The block terms grow with depth. The vocabulary term depends on vocabulary size and width. This is why embeddings can be a substantial fraction of a smaller model and account for a smaller share as more blocks are added.

### Encoder-only, encoder–decoder, and decoder-only

| Architecture | Attention pattern | Main use | Lecture example |
| --- | --- | --- | --- |
| Encoder-only | Bidirectional self-attention over the supplied input | Contextual representations for tasks such as classification | BERT |
| Encoder–decoder | Bidirectional encoder self-attention, causal decoder self-attention, and decoder cross-attention to encoder outputs | Conditional generation such as translation and summarization | T5 |
| Decoder-only | Causal self-attention over the token prefix | Autoregressive generation | GPT |

**Encoder-only.** BERT stands for *Bidirectional Encoder Representations from Transformers*. Its pretraining used masked language modeling, in which selected tokens are hidden or corrupted and predicted using the surrounding text on both sides. Original BERT also used next-sentence prediction, which distinguished actual neighboring sentences from randomly paired ones. The lecture noted that later models have used masked language modeling without the next-sentence objective. For downstream tasks such as sentiment or topic classification, a small task-specific head can use the pretrained encoder's contextual representations. Fine-tuning adapts the pretrained model to labeled examples for the target task.

**Encoder–decoder.** The encoder reads the full source sequence. At each target position, the decoder attends to the available target prefix and can use cross-attention to retrieve information from the source. In cross-attention, the queries come from the decoder and the keys and values come from the encoder. T5, the *Text-to-Text Transfer Transformer*, casts multiple tasks into a shared text-to-text format. A task prefix can specify “translate English to German” or “summarize,” followed by the input text. Even a classification task can produce a text label as its output. The same model can train across these tasks, with the task indicated by the input.

**Decoder-only.** A causal mask lets position \(i\) attend to positions \(j\le i\). Before the row-wise softmax, scores with \(j>i\) are set to \(-\infty\), so their attention weights become zero. During training, the shifted targets are already known, so the model can compute next-token predictions for all positions in a sequence together. During generation, the model selects tokens sequentially because each newly selected token extends the prefix for the next prediction. The entire supplied prompt is available as context when generating the first response token.
