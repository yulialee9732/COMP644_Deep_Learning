# 2.1 Sequence Modeling and RNNs

### Modeling a sequence

Words in a sentence, frames in a video, and observations over time are examples of sequential data. A sequence model uses the observations available so far to represent the current state and make predictions.

A Markov model of order \(k\) predicts the next state using the \(k\) most recent states. A first-order word model conditions the next word on one previous word, giving a bigram model. A second-order model conditions it on the two most recent words, giving a trigram model. Increasing the order lets the model use more history, but the number of possible contexts grows and individual contexts become harder to estimate from data.

### Recurrently updated hidden states

A recurrent neural network (RNN) reads the sequence one element at a time. The same learned function updates a continuous hidden-state vector at each step:

\[
h_t=f_\theta(h_{t-1},x_t).
\]

For a simple RNN, the update can be written as \(h_t=\tanh(W_{hh}h_{t-1}+W_{xh}x_t+b_h)\). The vector \(h_t\) is a learned representation of the prefix \(x_1,\ldots,x_t\). The update function is shared across time, so the RNN can process sequences of different lengths.

A prediction head can use \(h_t\) at every time step, for example to label the current word, predict the next word, or forecast the next weather observation. For a sequence-level classification task, a head can use the final state \(h_T\) to make one prediction about the entire input. Backpropagation trains the recurrent update and the prediction head jointly.

### Long sequences and backpropagation through time

Backpropagation through time follows the unrolled sequence of recurrent updates. A loss at a late time step sends its gradient back to earlier steps through repeated multiplication by the Jacobians of the update function. Products that contract repeatedly can cause gradients to vanish, while products that expand repeatedly can cause them to explode. As the distance between a prediction and the input that influenced it grows, learning that dependency can become harder.

The forward computation is also sequential. Computing \(h_{100}\) requires \(h_{99}\), which requires \(h_{98}\), and so on. This dependency limits how much computation can be parallelized across positions in a sequence.
