# 2.3 Attention & Transformers

### From recurrent updates to self-attention

In a recurrent model, information from the first position travels through \(L-1\) state updates to reach the last position. In full self-attention, the last position can attend directly to the first in a single layer. Think of the tokens as nodes in a graph. Full self-attention scores all ordered pairs of nodes, producing an \(L\times L\) matrix for a sequence of length \(L\). These scores can be computed together with matrix operations, which map well to GPUs.

A Transformer takes a vector per token and returns a refined vector per token. Context helps determine what the refined vector represents. For example, surrounding words can establish that “Carolina” refers to a UNC basketball team. In “The animal didn’t cross the street because it was too tired,” information from “animal” can help contextualize “it.”

### Queries, keys, and values

Each token vector produces three learned projections. The **query** represents what information the token is looking for. The **key** represents what other queries can match against. The **value** carries the information passed along when the token receives attention.

Using rows for tokens, let \(X\in\mathbb R^{L\times d_{\mathrm{model}}}\). For one attention head,

\[
Q=XW_Q,\qquad K=XW_K,\qquad V=XW_V.
\]

The query and key each have width \(d_k\), while the value can have width \(d_v\). For query position \(i\) and key position \(j\), the raw score is \(q_i^\top k_j\). Scaled dot-product attention computes

\[
A=\operatorname{softmax}_{\mathrm{row}}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right),
\qquad Z=AV.
\]

Row \(i\) of \(A\) says how much the output at position \(i\) uses each value vector. The output row is \(z_i=\sum_j A_{ij}v_j\). Dividing by \(\sqrt{d_k}\) controls how large the dot products tend to become as the key width grows, reducing softmax saturation. In self-attention, all three projections come from the same sequence.

### Multi-head attention

Different heads have their own query, key, and value projections. This allows them to form different attention patterns over the same input. A head may appear to track a relationship such as pronoun reference. The patterns are learned from the training objective.

The layer concatenates the head outputs and applies an output projection \(W_O\) to mix them and return to width \(d_{\mathrm{model}}\):

\[
\operatorname{MultiHead}(X)
=\operatorname{Concat}(Z_1,\ldots,Z_H)W_O.
\]

A common choice is \(d_k=d_v=d_{\mathrm{model}}/H\). With this convention, increasing the number of heads at a fixed model width narrows each head, so the combined projection widths stay the same.
