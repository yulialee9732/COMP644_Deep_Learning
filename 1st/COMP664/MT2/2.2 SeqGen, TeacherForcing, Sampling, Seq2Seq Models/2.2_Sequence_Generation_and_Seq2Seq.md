# 2.2 Sequence Generation, Teacher Forcing, Sampling, and Seq2Seq Models

### Next-token prediction and generation

An autoregressive language model maps a prefix \(w_1,\ldots,w_{t-1}\) to a probability distribution over the next token. A prediction head produces vocabulary logits from the current representation, and softmax converts the logits to probabilities. Repeating the next-token prediction defines a probability for the whole sequence:

\[
p(w_1,\ldots,w_T)=\prod_{t=1}^{T}p(w_t\mid w_1,\ldots,w_{t-1}).
\]

To generate text, choose a token from the current distribution, append it to the prefix, and compute the next distribution using the updated prefix. A start token can provide the initial input, and an end token can signal completion.

- **Sampling** draws the next token according to the predicted distribution. Repeating generation from the same prefix can produce different continuations.
- **Greedy decoding** chooses the highest-probability token at each step. The probability of a complete sequence is the product of the conditional probabilities along its path, so a locally optimal choice can lead to a lower-probability complete sequence.

### Teacher forcing

During training, the decoder receives the ground-truth token from the previous position as input and learns to predict the ground-truth token at the current position. For a target sequence \(y_1,y_2,y_3\), the inputs are \(\langle\mathrm{BOS}\rangle,y_1,y_2\) and the prediction targets are \(y_1,y_2,y_3\). This shifted alignment is the meaning of feeding the correct next token into the following step. During generation, the token the model actually selected becomes the next input.

### RNN encoder–decoder models

Sequence-to-sequence models take an input sequence and generate an output sequence, potentially of a different length. Machine translation is an example. An encoder RNN reads a source sentence and produces hidden states \(h_1,\ldots,h_L\). A decoder RNN generates the target sentence one token at a time, conditioned on the encoded input and the target prefix.

In the basic encoder–decoder model, the encoder passes its final hidden state to the decoder. This creates a fixed-size bottleneck because the final state has to carry all source information relevant to the output. The problem becomes more pronounced for long inputs.

### Attention in an RNN decoder

Attention gives the decoder access to the encoder's hidden state at each source position. At a target step \(t\), the decoder uses its current state to score how relevant each source state \(h_i\) is. Softmax turns these scores into attention weights \(\alpha_{ti}\) that sum to one across source positions. The decoder uses the weighted sum of the source states as a context vector:

\[
c_t=\sum_{i=1}^{L}\alpha_{ti}h_i.
\]

The decoder can compute a different context vector at each step. For example, translating “neural networks” into Spanish can produce “redes neuronales,” reversing the order of the corresponding words. When generating “redes,” the decoder can put more weight on “networks,” then shift its attention toward “neural” when generating “neuronales.” This is a soft alignment because the decoder can distribute weight across several source words. A translation attention map shows this pattern. Each row corresponds to a target step, each column to a source position, and each row sums to one. These alignments can emerge from training on sentence pairs without explicit word-by-word alignment labels.
