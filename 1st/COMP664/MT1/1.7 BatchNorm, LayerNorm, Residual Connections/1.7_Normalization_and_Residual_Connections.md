# 1.7 BatchNorm, LayerNorm, and Residual Connections

## Normalizing activations

Both batch normalization and layer normalization standardize activations using

\[
\hat x=\frac{x-\mu}{\sqrt{\sigma^2+\epsilon}},\qquad y=\gamma\hat x+\beta.
\]

The trainable scale \(\gamma\) and shift \(\beta\) let the network adjust the normalized representation. The axes used to compute \(\mu\) and \(\sigma^2\) determine which activations are normalized together.

| Method | Statistics during training | Statistics during inference |
| --- | --- | --- |
| BatchNorm | For dense layers, across examples for each feature. For typical convolutional BatchNorm, across batch and spatial axes for each channel. | Uses running estimates collected during training. |
| LayerNorm | Across the selected feature dimensions of each example or token. | Computes statistics from the same feature dimensions of the current example or token. |

For a dense activation matrix \(X\in\mathbb R^{N\times D}\) with one example per row, BatchNorm computes statistics down each column and LayerNorm across each row. BatchNorm's training statistics depend on the examples in the minibatch. LayerNorm can normalize one example or token independently of the others.

## Residual connections

A residual block computes \(y=x+F(x)\), where \(F\) is a learned transformation. The identity path carries the input forward directly, and \(F\) learns a correction. If \(F(x)=0\), the block implements the identity. When dimensions differ, a projection can align the skip path with the residual branch before addition.

The local Jacobian is \(I+J_F(x)\). In backpropagation, the identity term gives the incoming gradient a direct path through the addition. This makes it easier to preserve useful features and train a deep stack. In a residual CNN, \(F\) can contain convolution, normalization, and nonlinear activations. The skip path adds its output to the input with compatible shapes.
