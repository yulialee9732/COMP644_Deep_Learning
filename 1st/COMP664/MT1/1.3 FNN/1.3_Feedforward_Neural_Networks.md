# 1.3 Feedforward Neural Networks

## Layers and learned features

A feedforward neural network passes an input through a sequence of layers to produce an output. A fully connected feedforward network is commonly called a multilayer perceptron (MLP). Its hidden layers learn intermediate features. Linear regression can be viewed as a one-layer network with a linear output.

For a two-layer MLP with examples as rows,

\[
H=\phi(XW_1+b_1),\qquad \hat Y=g(HW_2+b_2).
\]

Here \(\phi\) is an elementwise hidden activation and \(g\) depends on the task. A real-valued regression output can use the identity, binary classification can use sigmoid, and multiclass classification can use softmax. If \(X\) has shape \(N\times3\) and \(W_1\) has shape \(3\times4\), then \(H\) has shape \(N\times4\). Each row represents one example and each column represents one hidden unit.

Stacking linear transformations alone gives \(XW_1W_2=XW'\). Adding biases still gives a single affine transformation. Hidden nonlinearities allow the network to learn more expressive functions and reduce the need to design nonlinear input features by hand.

## Activation functions

| Activation | Function | Derivative |
| --- | --- | --- |
| Sigmoid | \(\sigma(z)=1/(1+e^{-z})\) | \(\sigma(z)(1-\sigma(z))\) |
| Tanh | \(\tanh(z)=(e^z-e^{-z})/(e^z+e^{-z})\) | \(1-\tanh^2(z)\) |
| ReLU | \(\max(0,z)\) | \(0\) for \(z<0\), \(1\) for \(z>0\) |
| Leaky ReLU | \(\max(0.01z,z)\) | \(0.01\) for \(z<0\), \(1\) for \(z>0\) |

Sigmoid maps to \((0,1)\) and tanh maps to \((-1,1)\). Both saturate for large-magnitude inputs, where derivatives become small. ReLU passes positive inputs through and sets negative inputs to zero. Leaky ReLU retains a small gradient on the negative side. At the kink at zero, implementations choose a derivative convention.

## Piecewise-linear functions and universal approximation

A shifted ReLU \(\operatorname{ReLU}(x-b)\) introduces a breakpoint at \(b\). Multiplying it by \(a\) changes the slope by \(a\) at the breakpoint. For example,

\[
\operatorname{ReLU}(x)-\operatorname{ReLU}(x-1)
\]

is zero for \(x\le 0\), ramps linearly from zero to one on \([0,1]\), and stays at one for \(x\ge1\). Combining shifted ReLUs lets a hidden layer approximate a continuous one-dimensional curve with piecewise-linear segments.

Under the universal approximation theorem's conditions, a network with one sufficiently wide hidden layer and a suitable nonlinear activation can approximate continuous functions on compact domains arbitrarily closely. This is a statement about representational capacity. Finding the weights and generalizing to unseen data are separate problems.
