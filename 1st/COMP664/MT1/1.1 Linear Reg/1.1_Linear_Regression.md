# 1.1 Linear Regression

## Model and design matrix

For example \(i\), let \(x_i\in\mathbb R^d\) be its feature vector and \(y_i\in\mathbb R\) its target. Linear regression predicts \(\hat y_i=w^\top x_i+b\). The intercept \(b\) can be absorbed into \(w\) by adding a constant feature equal to one. For example, a model could predict energy consumption from floor area, outdoor temperature, and last month's consumption.

With examples as rows, \(X\in\mathbb R^{N\times d}\), \(w\in\mathbb R^d\), and \(\hat y=Xw\in\mathbb R^N\), using the convention that the intercept is already included if needed.

## Squared error and gradient

Define the sum of squared errors by

\[
L(w)=\sum_{i=1}^N(\hat y_i-y_i)^2=\|Xw-y\|_2^2.
\]

The scalar and matrix forms of its gradient are

\[
\frac{\partial L}{\partial w_j}
=2\sum_i(\hat y_i-y_i)x_{ij},
\qquad
\nabla_w L=2X^\top(Xw-y).
\]

The gradient for each feature sums its values weighted by the signed prediction residual. Mean squared error divides the loss and gradient by \(N\). Using a factor of \(1/2\) cancels the factor of two in the derivative. These scaling conventions have the same minimizers and change the effective gradient step size. Squared error is convex in the linear weights.

## Batch, stochastic, and minibatch updates

For learning rate \(\eta>0\), gradient descent takes the step \(w\leftarrow w-\eta g\).

| Method | Examples used to compute \(g\) per update |
| --- | --- |
| Full-batch gradient descent | All training examples |
| Stochastic gradient descent | One sampled example in the strict definition |
| Minibatch SGD | A sampled group of examples |

For the mean loss, average the per-example gradients within the minibatch. An epoch is a pass through the training data. Batch size is a hyperparameter. Smaller batches generally produce noisier gradient estimates and give more updates per epoch. Minibatches let the model use vectorized computation while updating more often than full-batch training.
