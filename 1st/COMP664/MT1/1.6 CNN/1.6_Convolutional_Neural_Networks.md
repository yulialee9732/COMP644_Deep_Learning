# 1.6 Convolutional Neural Networks

## Local connections and shared filters

A convolutional layer applies each learned filter at many spatial locations. A filter uses a local patch and spans the input channels. One filter produces one feature map. For input shape \(H\times W\times C_{\mathrm{in}}\), \(C_{\mathrm{out}}\) filters of spatial size \(K_h\times K_w\) produce \(C_{\mathrm{out}}\) output channels and use \(K_hK_wC_{\mathrm{in}}C_{\mathrm{out}}\) weights, plus one bias per output channel if used. The parameter count is independent of the number of spatial locations because the weights are shared.

Each output value is a dot product between the corresponding patch and filter, plus its bias. Deep learning libraries commonly implement this operation as cross-correlation, applying the filter without flipping it. Moving a pattern in the input can move its activation in the output. This is translation equivariance, subject to boundary and stride effects.

## Stride, padding, and output size

Stride controls how far the filter moves between successive positions. Padding adds values around the boundary, often zeros. With symmetric padding \(P\), kernel width \(K\), stride \(S\), and unit dilation, apply the formula separately to each spatial axis:

\[
D_{\mathrm{out}}=\left\lfloor\frac{D_{\mathrm{in}}+2P-K}{S}\right\rfloor+1.
\]

For example, \(D_{\mathrm{in}}=32\), \(K=3\), \(P=1\), and \(S=1\) yield an output size of \(32\). Increasing the stride to \(2\) yields \(16\). The output depth comes from the number of filters.

## Pooling and backpropagation

Max pooling reports the largest activation in each window. Average pooling reports the mean. Pooling usually reduces spatial dimensions without introducing learned weights and can make features less sensitive to small shifts within a window.

During backpropagation, a max-pooling window sends its gradient to the input selected as the maximum in the forward pass, using the implementation's tie convention. Average pooling distributes the gradient evenly across the window. A convolutional filter receives gradient contributions from every output location where it was used. Backpropagation sums those contributions for each shared weight.

## How the layers fit together

Early layers can detect local patterns such as edges. Stacking layers grows the receptive field, letting later features combine evidence over larger regions. A classification CNN can pass its feature maps through pooling or flattening and then a classifier. The lecture discussed LeNet for handwritten character recognition and AlexNet for ImageNet. AlexNet combined convolution, pooling, and fully connected classification layers, used ReLU activations and dropout, and illustrated the role of GPU training in larger image classifiers.
